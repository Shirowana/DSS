可以。我们这次把符号**彻底固定**，以后都按这一套说，不再来回切换 `S / core / basis / Lambda` 这些名字。

当前新 DSS 的核心关系，和你文档里写的是一致的：

[
\Delta W = A^{-1}\lambda B^{-1}
]

其中真正训练的是稀疏的 (\lambda)；`coefficient` 和 `coefficient_indices` 只是它的稀疏存储形式，`candidate_indices` 是只做 probe 的临时位置。这个定义和新 DSS 说明一致。
而 (A,B) 的来源是离线 diagonalization：先找 (A,B) 让 (A W B) 尽量接近对角/带状，再用它们的逆恢复原权重空间，所以恢复公式本来就该写成逆矩阵形式。`diagonalization.py` 末尾也明确写了应使用 (A^{-1},B^{-1}) 重构。

## 一、统一后的符号

我固定用 **PyTorch / batch 行向量** 写法，这样最贴近你现在代码。

设某个线性层：

* 输入维度：(n)
* 输出维度：(m)
* batch 大小：(B)

那么：

[
x \in \mathbb{R}^{B\times n}, \qquad y \in \mathbb{R}^{B\times m}
]

基座权重：

[
W_0 \in \mathbb{R}^{m\times n}
]

DSS 增量权重：

[
\Delta W \in \mathbb{R}^{m\times n}
]

最终有效权重：

[
W = W_0 + \Delta W
]

离线得到并冻结的变换矩阵：

[
A^{-1} \in \mathbb{R}^{m\times m}, \qquad B^{-1} \in \mathbb{R}^{n\times n}
]

真正被训练的稀疏矩阵：

[
\lambda \in \mathbb{R}^{m\times n}
]

于是：

[
\Delta W = A^{-1}\lambda B^{-1}
]

---

## 二、稀疏参数的存储方式

(\lambda) 在实现里不是完整 dense 矩阵，而是稀疏存储：

* `coefficient[k]`：第 (k) 个 elite slot 的数值
* `coefficient_indices[k]`：第 (k) 个 elite slot 在 (\lambda) 中的位置（flat index）
* `curr_count`：当前 elite 的数量
* `candidate_indices`：当前候选位置（只 probe，不参与前向）

也就是说，当前真正生效的 elite 集合是：

[
{(p_k, c_k)}_{k=1}^{K},\qquad K=\text{curr_count}
]

其中：

* (p_k) 是 flat index
* (c_k) 是对应的数值

flat index 和二维坐标 ((r_k, s_k)) 的关系是：

[
r_k = \left\lfloor \frac{p_k}{n} \right\rfloor,\qquad
s_k = p_k \bmod n
]

于是：

[
\lambda_{r_k,s_k} = c_k
]

其他未被选中的位置都是 0。

---

## 三、前向传播公式

### 1. base 分支

标准线性层：

[
y_{\text{base}} = x W_0^\top
]

---

### 2. DSS 分支

先把输入变换到新的输入坐标系：

[
u = x(B^{-1})^\top
]

这里：

[
u \in \mathbb{R}^{B\times n}
]

然后用稀疏矩阵 (\lambda) 做核心线性映射：

[
v = u\lambda^\top
]

这里：

[
v \in \mathbb{R}^{B\times m}
]

再把结果映回原输出空间：

[
\Delta y = v(A^{-1})^\top
]

最后总输出：

[
y = y_{\text{base}} + \Delta y
]

把它合起来写，就是：

[
y = xW_0^\top + x(B^{-1})^\top \lambda^\top (A^{-1})^\top
]

这和

[
y = x(W_0+\Delta W)^\top
]

完全等价，因为：

[
\Delta W = A^{-1}\lambda B^{-1}
]

---

## 四、把前向再写成“按 slot 求和”的形式

因为 (\lambda) 是稀疏的，如果 elite 位置是 ((r_k,s_k))，数值是 (c_k)，那么：

[
v_{:,r_k} \mathrel{+}= c_k \cdot u_{:,s_k}
]

也就是说，每个非零 slot 的含义都是：

> 读输入第 (s_k) 列，乘以 (c_k)，加到输出第 (r_k) 列。

因此：

[
v = u\lambda^\top
]

也可以展开成：

[
v = \sum_{k=1}^{K} c_k , u_{:,s_k}, e_{r_k}^\top
]

其中 (e_{r_k}) 是第 (r_k) 个标准基向量。

---

## 五、反向传播公式

设损失为 (L)。

### 1. 对 (v) 的梯度

先从后面传回来。因为

[
\Delta y = v(A^{-1})^\top
]

所以：

[
\frac{\partial L}{\partial v}
=============================

\frac{\partial L}{\partial \Delta y}, A^{-1}
]

记作：

[
g_v = \frac{\partial L}{\partial v}
\in \mathbb{R}^{B\times m}
]

---

### 2. 对 (\lambda) 的 dense 梯度

因为

[
v = u\lambda^\top
]

所以：

[
\frac{\partial L}{\partial \lambda}
===================================

g_v^\top u
]

其中：

[
g_v^\top \in \mathbb{R}^{m\times B},\qquad
u \in \mathbb{R}^{B\times n}
]

所以：

[
G_\lambda := \frac{\partial L}{\partial \lambda}
\in \mathbb{R}^{m\times n}
]

这就是你现在 hook 里看到的那张 `grad_core`。

---

### 3. 对变换后输入 (u) 的梯度

同样因为

[
v = u\lambda^\top
]

所以：

[
\frac{\partial L}{\partial u}
=============================

g_v \lambda
]

---

### 4. 再传回原输入 (x)

因为

[
u = x(B^{-1})^\top
]

所以：

[
\frac{\partial L}{\partial x}
=============================

\frac{\partial L}{\partial u} , B^{-1}
]

---

## 六、elite 参数的梯度

真正被优化器更新的不是整张 (G_\lambda)，而只是 elite 对应的位置。

如果第 (k) 个 elite slot 在 ((r_k,s_k))，那么它的梯度就是：

[
\frac{\partial L}{\partial c_k}
===============================

(G_\lambda)_{r_k,s_k}
]

也就是：

[
\frac{\partial L}{\partial c_k}
===============================

\sum_{b=1}^{B}
g_v[b,r_k]\cdot u[b,s_k]
]

这就是为什么一个 slot 的梯度可以理解成：

> 输出梯度第 (r_k) 列 和 输入第 (s_k) 列 的逐元素乘积，再对 batch 求和。

---

## 七、candidate probe 梯度

candidate 不参与前向，因此不会进入真正的训练参数更新；
但它们的梯度仍然可以从同一张 dense 梯度图 (G_\lambda) 中直接取出。

如果某个 candidate 位置是 (q_j)，对应二维坐标 ((\hat r_j,\hat s_j))，那么 probe grad 就是：

[
g^{\text{cand}}_j
=================

(G_\lambda)_{\hat r_j,\hat s_j}
]

也就是 hook 里做的事情：

[
g^{\text{cand}} = G_\lambda.\mathrm{reshape}(-1)[\text{candidate_indices}]
]

这些梯度**不进入 optimizer step**，只用于：

* stage1：判断哪些 candidate 应该晋升为 elite
* stage2：判断哪些 candidate 值得 grow

这也正是新 DSS 文档里写的：candidate 不参与前向，也不会进入 optimizer，只在 backward 里读取梯度做两阶段选择。

---

## 八、参数更新公式

### 1. elite 的训练更新

设当前 optimizer 是 `DSSAdamW`，那么真正更新的是：

[
c_k \leftarrow \text{OptimizerStep}\left(c_k,\ \frac{\partial L}{\partial c_k}\right)
]

也就是说，只有：

[
{c_k}_{k=1}^{K}
]

这些 elite 数值被更新。

---

### 2. candidate 不做参数更新

candidate 位置的 probe grad 只做统计，不做 step：

[
g^{\text{cand}}_j \rightarrow \text{collect_probe_grads}(\cdot)
]

不会有：

[
\text{candidate value} \leftarrow \text{optimizer step}
]

因为 candidate 根本不是长期训练参数。

---

### 3. stage1 的统计量

你现在新 DSS 文档里明确写的是旧语义：

[
x_{\text{mean}} = \left| \frac{\text{grad_cache}}{\text{grad_count}} \right|
]

也就是：

[
x_{\text{mean}} = \left| \operatorname{mean}(g) \right|
]

不是 `mean(abs(g))`。

它随后用于：

* 更新分位数阈值
* 按阈值从 candidate 中选晋升对象

---

### 4. stage2 的更新

stage2 不是直接用当前一步的梯度立刻替换，而是：

* 先在一个窗口里累计 candidate 统计
* 到 update boundary 再做 prune/grow
* 同时重写 optimizer state

所以 stage2 的“参数更新”分成两部分：

#### a. 正常训练更新

elite 的 (c_k) 继续按 optimizer 更新

#### b. 结构更新

在边界处做：

* prune 掉一部分旧 elite
* grow 进一部分新 candidate
* 对应修改 `coefficient_indices`
* 并对 `DSSAdamW` 做 slot-level state rewrite

---

## 九、最后整理成一套最简公式

### 定义

[
W = W_0 + \Delta W,\qquad
\Delta W = A^{-1}\lambda B^{-1}
]

### 前向

[
y_{\text{base}} = xW_0^\top
]
[
u = x(B^{-1})^\top
]
[
v = u\lambda^\top
]
[
\Delta y = v(A^{-1})^\top
]
[
y = y_{\text{base}} + \Delta y
]

### 反向

[
g_v = \frac{\partial L}{\partial \Delta y}, A^{-1}
]
[
G_\lambda = \frac{\partial L}{\partial \lambda} = g_v^\top u
]
[
\frac{\partial L}{\partial u} = g_v\lambda
]
[
\frac{\partial L}{\partial x} = \frac{\partial L}{\partial u}, B^{-1}
]

### elite 梯度

[
\frac{\partial L}{\partial c_k} = (G_\lambda)_{r_k,s_k}
]

### candidate probe 梯度

[
g^{\text{cand}}*j = (G*\lambda)_{\hat r_j,\hat s_j}
]

### 参数更新

* elite：进入 `DSSAdamW`
* candidate：只做统计，不 step
